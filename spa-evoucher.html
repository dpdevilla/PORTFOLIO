Built a custom Spa E-Voucher system connecting Shopify, Make.com, and Klaviyo. Customers can select their services through a custom landing page and submit their information for automated voucher processing, including a unique voucher ID and QR code.

01 — THE CHALLENGE

The Voucher Process Needed Automation

The goal was to create a smoother process for collecting customer information and delivering e-vouchers while reducing manual processing.

01

The Problem

Customer information, selected services, voucher identification, and customer communication needed to move through multiple steps.

02

The Solution

I created a custom Shopify landing page and connected it to an automated Make.com workflow and Klaviyo communication process.

02 — IMPLEMENTATION

How I Set It Up

The implementation connected the customer-facing Shopify experience with the automation and communication layers.

  • Created a custom Shopify e-voucher landing page.
  • Added customer information fields.
  • Added spa service selection.
  • Added validation for required information.
  • Connected the form to a Make.com webhook.
  • Created a unique voucher ID.
  • Generated a QR code using the voucher ID.
  • Passed voucher information to Klaviyo.
  • Used automated email communication for the voucher.
  • Stored voucher information for tracking and redemption.
