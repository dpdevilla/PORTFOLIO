Custom Klaviyo Event Signup Form

I created a custom Shopify page for an event signup form. The Klaviyo form was added to the page and custom JavaScript was used to remove the default delay.

01 — THE CHALLENGE

The Form Had a Delay

The event signup form was using Klaviyo's default popup behavior, which added a delay before the form was shown.

01

The Problem

Visitors had to wait for the Klaviyo popup to appear before they could access the event signup form.

02

What I Did

I created a separate Shopify page template and added the Klaviyo signup form directly to the page. I then used JavaScript to control the form display and remove the delay.

02 — IMPLEMENTATION

How I Built It

I kept the existing Klaviyo form and used a custom Shopify template to give it its own page.

  • Created a custom Shopify page template.
  • Added the existing Klaviyo signup form.
  • Added custom JavaScript for the form behavior.
  • Removed the default display delay.
  • Tested the page and form behavior.

04 — CODE

JavaScript

A small JavaScript function was added to the Shopify page to work with the Klaviyo form after the page loads.

JavaScript 
document.addEventListener("DOMContentLoaded", function () {

  const form = document.querySelector(
    '[data-testid="form-component"]'
  );

  if (!form) return;

  form.style.display = "block";

});

This is a simplified example of the JavaScript used to control the form display. The actual selector can depend on the Klaviyo form setup.

05 — RESULT

A Simpler Signup Page

The event signup form now has its own Shopify page instead of relying on the default popup display.

I was able to keep the existing Klaviyo form while having more control over how and when it is displayed.
